# GitFinder 2.0.0-alpha.17 验证记录

## 修复范围

- 关系白板首屏不再等待 Coolify 网络拓扑；本机白板、仓库和目录资源先显示，Coolify 在后台只读同步。
- 项目扫描和 Coolify 任一请求迟到或不返回时，不再让页面停留在“正在载入关系白板”。
- Coolify 数据源别名成为服务器卡片的主要识别名称，同时保留 API 返回的真实服务器名；同一数据源包含多台服务器时使用“连接名称 · 服务器名”。
- 每个白板元素支持保持原名、替换标题、在原名前追加、在原名后追加和作为副标题五种显示方式。
- 卡片显示别名属于白板布局元数据，不修改 Coolify、项目或 Git 仓库的真实名称，并可随白板导入导出。

## 布局后续

- “仓库 → 部署 → 访问端点”适合作为可切换的部署泳道布局；本版本保留现有自由白板和自动布局，泳道标题、环境子泳道与未关联资源区列入后续垂直切片。

## 验证边界

- Coolify 仍为只读数据源；修复不会触发部署、重启、写入服务器或修改 Git。
- 本记录只覆盖 macOS 本机验证；Windows 仍需在真实 Windows 环境单独构建和验收。

## 验证结果

- 定向回归测试覆盖“Coolify 请求永久不返回时本地白板仍先完成载入”，50ms 测试门槛内通过。
- `npm run check`：697/697 通过；192 个 JavaScript 文件通过语法检查。
- `/Applications/GitFinder 2 Alpha.app` 冷启动界面捕获约 580ms，已显示完整白板工具栏且没有“正在载入关系白板”。
- 实际界面显示服务器标题 `con01`，副标题保留 `Coolify 主机 localhost`；后台同步期间资源面板仍可立即开关。

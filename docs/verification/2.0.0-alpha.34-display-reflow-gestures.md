# alpha.34 白板尺寸联动与鼠标交互

日期：2026-08-31。范围仅为本轮白板显示和交互修复；不修改 Coolify 数据、凭据或服务器配置。

## 已实现

- 普通滚轮/双指滚动平移画布；Ctrl 或 Cmd 加滚轮围绕指针缩放，触控板捏合沿用 Chromium 的 Ctrl-wheel 通道。
- 左键拖动卡片移动元素，左键拖动空白直接框选，不再依赖 Shift。群组内部空白也可框选，群组标题用于移动整组。
- 中键或空格加左键拖动平移，保留 WASD/方向键；输入框、按钮及详情编辑区不触发默认框选。
- 删除资源库“当前白板 / 全部资源”切换按钮，保留分类、搜索和已放入白板资源的定位入口，不删除任何资源。
- 调整卡片宽高、缩放、字号或间距时，使用实际测量卡片高度适配列间距及群组边界；手动排列保留原有列顺序、错位和额外留白，嵌套群组递归调整。
- 一次滑块拖动只记录一次撤销，连续输入使用同一基准避免累积偏移；动态卡片位置及群组尺寸保存在本地覆盖配置中。

## 根因

旧流程在重新生成动态拓扑后恢复旧的 x/y，显示阶段仅做纵向碰撞处理。宽度变大时，邻列没有同步让位，而纵向处理又会把相邻列卡片向下推。显式保存的群组宽高也没有跟随卡片尺寸变化。

现在尺寸调整不再依赖重新读取拓扑；测量新尺寸后按原列、行关系调整坐标和边界。相互不重叠的上下区域不会因为下方群组变宽而被横向推远。筛选及运行状态更新不执行此尺寸排列流程。

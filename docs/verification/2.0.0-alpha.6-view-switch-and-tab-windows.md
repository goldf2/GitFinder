# GitFinder 2.0.0-alpha.6 视图切换与标签页独立窗口验证记录

## 目标

1. 修复从关系白板等工作区切回“文件浏览”时，偶尔点击后界面没有切换的问题。
2. 允许任一工作区标签页在独立应用窗口中显示。

## 问题与根因

用户录屏中，模式菜单里的“文件浏览”在首次按下后仍停留在关系白板，稍后才完成切换。代码检查确认有两个叠加因素：

- 模式菜单只监听完整 `click`，按下阶段没有立即响应；
- 关系白板的异步载入在视图已经关闭后仍可能完成，并重新渲染旧内容和绑定键盘事件。

修复后，主键 `pointerdown` 会立即通过统一的 `switchMode` 流程切换视图；键盘和辅助功能触发的 `click` 仍保留。关系白板同时使用打开请求代次和当前视图检查，已关闭的迟到请求不能再占用内容区。

## 标签页独立窗口

- 标签页右键菜单新增“在新窗口中打开”。
- 系统“文件”菜单新增“在新窗口中打开当前标签页”。
- 新窗口收到经过规范化和大小限制的单标签快照，只显示所选标签页。
- 原窗口的标签页仍保留；当前实现是“打开独立副本”，不是把标签从原窗口移走。
- 独立窗口的标签、路径、历史和视图变化只在该窗口生命期内生效，不覆盖主窗口的全局标签会话和 `lastPath`。
- 应用菜单和二次启动会优先作用于当前焦点窗口。

## 当前边界

独立窗口不会在应用重启后自动恢复，也不支持把标签拖出或拖回窗口；这些属于后续多窗口会话功能，不影响本次“在新窗口显示标签页”的首个可用切片。

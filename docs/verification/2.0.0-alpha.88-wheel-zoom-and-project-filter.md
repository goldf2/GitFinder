# 2.0.0-alpha.88 白板滚轮缩放与 Project 筛选层级

日期：2026-09-04

## 行为

- 鼠标滚轮或触控板双指滚动直接围绕指针缩放白板；中键或空格加拖动继续用于平移。
- 筛选时 Project 容器保持完整可见，直接命中的 Project 仍显示命中高亮；容器内未命中的部署卡片继续按设置弱化。
- 这些交互由 React Flow 配置和共享适配器实现，不恢复旧白板的自定义滚轮事件。

## 验证

- `npm run check`：969 项测试全部通过，235 个 JavaScript 文件通过语法检查。
- 隔离页面 `scripts/visual-fixtures/relationship-groups.html?wheel-zoom=88`：滚轮后视口由 `scale(0.8)` 变为 `scale(1.11579)`，缩放锚点随指针变化。
- Project 堆叠示例筛选“部署 2”后，Project 容器无弱化类，命中部署为 `is-filter-match`，其余部署为 `is-filter-muted`。

浏览器隔离验证不等同于安装版验收；双平台安装包由 GitHub Actions 干跑继续验证。

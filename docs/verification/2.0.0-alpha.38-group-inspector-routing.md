# alpha.38 群组属性与连线验收

日期：2026-08-31。

## 用户反馈与修复

- 群组“查看属性”和“编辑”无响应：复现为详情组件折叠后，命令只定位内部字段，没有解除折叠。现明确展开组件，保留左右停靠位置、排序和未保存输入，并把焦点定位到表单；群组卡片铅笔使用同一入口。
- 录屏中的连线大段直角绕行：原路由只尝试成对的左右/上下端口，且采用第一条可行曲线。现支持四个边的混合及同侧端口，比较有限数量、不同弯曲程度的曲线后选择较短可行项；无可用曲线时仍使用有界避障折线。不会修改连接的语义、方向或节点位置。

## 验证

- 自动化：831/831 测试通过；203 个 JavaScript 文件语法检查通过。
- 新回归：折叠详情的属性/重命名/注释命令、混合方向端口、同侧曲线绕障、多排 36 个部署汇聚到主机。
- 浏览器正式组件：群组重命名保存；详情移到左侧并折叠后，“查看属性”会展开；名称编辑正确获取焦点。
- 浏览器 6 节点/4 关系用例：4 条实际 SVG 连线均为曲线；每条采样 40 点，未穿过卡片内部。
- macOS 打包、签名检查及安装已完成（构建提交 `85ddc58`），安装版可见 alpha.38。验收期间用户新增更大缩放范围、缩短大弧线及树状结构要求，最终交互验收转入 alpha.39；不将本版安装成功当作完整交互验收。

本次沿用 ad-hoc 本机开发包；Windows 安装运行不在本次验收范围。云服务/通知方案仍仅为规划。本记录不替代用户确认有效后应归档的修复报告。

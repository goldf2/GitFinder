# 2.0.0-alpha.21 卡片比例与左侧关注色条修复

## 根因及范围

此前 alpha.20 的源码断言没有证明与批准原型的实际渲染一致。安装版保存的卡片比例为 135%，但代码只放大外框，没有同步放大图标、文字、按钮和留白；旧配色及阴影规则也仍在生效。详情态 `overflow: hidden` 还会裁掉外置色条与连接点。

- 使用独立卡片表面统一缩放外观，保留世界坐标、拖动、关系及单卡配置。
- 按批准原型对齐字体、边框、阴影、状态底色、状态徽标和详情分区。
- 左侧紫色待办、橙色提醒、红色逾期与顶部运行状态独立。没有未完成任务时不显示色条。
- 展开状态不再裁切外侧色条；连接点在色条上层，只读 Coolify 卡片也显示连接点，但不因此开放关系写入。
- 实测内容高度用于临时避让布局，详情展开不改写保存坐标；连线连接实际端口位置，不再连接卡片高度中点。
- 不修改图标、Coolify 凭据、真实任务、资源身份或服务器配置。

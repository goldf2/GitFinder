# GitFinder 2.0.0-alpha.8 关系属性栏视口修复

## 问题现象

关系白板右侧属性栏仍占据宽度，但节点或关系的属性内容不可见，呈现为空白区域。

## 根因

白板主体使用 CSS Grid，但没有把唯一网格行限制为可收缩高度。左侧资源列表的固有内容高度将白板主体从实际可视的约 646px 撑到约 2682px；外层工作区虽然设置了 `overflow: hidden`，仍可被浏览器或辅助功能程序化滚动，导致属性栏顶部内容被卷出视口。

## 修改

- 白板主体使用 `grid-template-rows: minmax(0, 1fr)`，只占当前可用高度。
- 白板主体隐藏自身溢出，禁止它成为隐式滚动容器。
- 左侧资源栏、画布和右侧属性栏显式允许收缩到网格高度。
- 长资源列表继续只在左侧内部滚动，长属性内容继续只在右侧内部滚动。

# GitFinder 2 Alpha 2.0.0-alpha.20 白板卡片与类别分列验证

## 范围

- 严格以 `prototypes/relationship-card-overview/index.html` 的卡片尺寸、层级、状态色、状态胶囊、注意事项色条和详情按钮为正式白板视觉基准。
- 卡片支持绿色正常、红色预警、灰色停止或无效三类状态；Git 仓库正常状态统一显示为绿色“已同步”。
- 待办、提醒、逾期和“无待办”在简略卡片中保持可见；详情可单独或统一展开，展开时重新计算同列节点位置。
- 白板显示设置提供横向间距和纵向间距滑块，并写入白板本机配置。
- 自动整理使用关系辅助排序与碰撞规避；“按类别分列”按项目、仓库、部署、主机、访问点建立固定列。
- 自动整理和类别分列最低保持 100% 卡片比例，不再为一次容纳全部节点而将卡片缩小；显式“适合”仍可用于全局总览。
- macOS 源码运行和打包应用统一使用批准的新 GitFinder 图标。

# 2.0.0-alpha.47 群组标题避让

## 问题与修复

群组标题放在容器外，保持固定屏幕字号；布局原来仅计算容器矩形。缩小至总览比例时，组间世界坐标间距缩小，下一组标题会进入上一组容器并被卡片覆盖。

- 排列为群组标题添加独立占位，不写入容器尺寸，不改变组内相对坐标或成员关系。
- 按排列后适合内容的缩放比例计算留白（标题、6px 偏移及余量共 40 屏幕像素）；有界预计算最多 8 次，每次从相同的已测量矩形开始。
- 仅显式整理/切换布局时应用，不在普通缩放时重排手动坐标，不改下级联动逻辑及标题字体。
- 已有白板保留旧坐标；通过「布局 → 整理布局」应用新留白，可撤销。

## 验证

- 修改前：正式控制器树状样例在约 15% 缩放下，7 个项目标题中 3 个与其他容器相交，同时有 6 次与卡片相交。
- 新回归在旧代码中 5/7 失败，均为标题被其他群组或主机遮挡；修复后 7/7 通过。覆盖六种布局、低比例适合内容、重复整理、普通缩放不改坐标、容器尺寸与组内偏移保持。
- `npm run check`：913/913 测试通过，211 个 JavaScript 文件语法检查通过。下级联动、全局自动排列与旧布局回归均通过。
- 浏览器逐项点击向右树状、向下树状、左右分叉、环绕放射、按类别分列、紧凑排列：均为 56 个可见元素、7 个群组标题，标题与容器/卡片相交数为 0；实测适合内容缩放约 5%–14%。这是演示数据验收，不保证任意手动重叠布局或继续无限缩小后标题仍不相交。
- `verify:icons`、`verify:release-source`、`git diff --check`、Mac 开发包产物门禁通过。

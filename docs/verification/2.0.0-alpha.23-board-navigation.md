# 2.0.0-alpha.23 白板视图导航

## 操作

- 点击画布空白处或卡片空白处后，WASD / 方向键平移视角；按住可连续移动，Shift 三倍加速。
- Ctrl + 双指滚动平移白板，支持横向、纵向、斜向及细粒度滚动；普通滚轮保留原有缩放。
- Alt/Option + 方向键微调选中卡片；加 Shift 使用较大步长。
- 平移只改变视口，不改变节点位置、连线、缩放或编辑撤销记录；视口沿用现有本机保存机制。
- 输入框、可编辑内容、菜单和可见弹窗不触发键盘平移；不拦截系统组合键或输入法组合输入。关闭的对话框模板不阻止平移。
- 保持即时响应，不新增动画、惯性、依赖或设置项。

## 验证

- `npm run check`：725 项测试通过，194 个应用 JavaScript 文件语法检查通过；`npm run pack` 源码和产物门禁通过。
- 单元回归覆盖 WASD/方向键、Shift 加速、按住重复、缩放无关步长、输入及弹窗隔离、隐藏对话框、Ctrl 滚动双轴和像素/行/页单位、普通滚轮缩放锚点。
- 正式 Controller 的隔离浏览器夹具验证：D 令世界从 `translate(120px,90px)` 移至 `translate(80px,90px)`；Shift + 上移至 `translate(80px,210px)`；输入备注 `wasd` 和方向键不改变视口。节点自身坐标不随平移变化。
- 首次安装版核验发现：全局查询把未显示的对话框模板也当作阻断条件。已改为检查对话框实际布局可见性并增加回归用例。
- 修正后的安装版实际验证：点击画布后 D 使卡片、网格及连线整体向左，Shift + 上方向键使内容整体向下；随后以反向键恢复原视角，卡片大小及相对位置不变。界面确认版本 `v2.0.0-alpha.23`。
- Ctrl + 双指操作的事件逻辑已测试；自动化工具不能模拟实体触控板的双指手势，硬件手感仍需用户确认。

# 2.0.0-alpha.89 Project 关联筛选与跨平台验证

日期：2026-09-04

## 行为

- Project 容器内任一部署直接命中筛选时，容器及标题保持正常显示。
- 与容器内部署相连的访问点命中时，也视为该 Project 有命中内容，容器及标题保持正常显示。
- 只有 Project、本组部署及其关联访问点均未命中时，Project 容器才随未命中内容弱化；卡片自身仍显示命中、上下文或弱化状态。

## 验证

- 适配器回归覆盖部署命中、关联访问点命中和整组未命中三个场景。
- Git 提交时间测试同时接受 ISO 8601 的 `Z` 与数字时区偏移。
- CSS 复用测试读取源码时统一换行符，避免 Windows CRLF 造成伪失败。
- `npm run check`：972 项测试全部通过，235 个 JavaScript 文件通过语法检查。
- 隔离白板切换为 Coolify 项目分组后筛选 `mes.example.com`：两个关联访问点为 `is-filter-match`，两个关联部署为 `is-filter-context`，所属两个 Project 容器均无弱化类；无关视觉群组为 `is-filter-muted`。

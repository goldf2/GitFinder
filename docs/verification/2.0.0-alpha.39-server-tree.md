# alpha.39 树状白板、缩放与连线

日期：2026-08-31。

## 实现

- 新增“服务器树状图”入口，在本机白板中创建独立视图副本，保留原白板和布局。服务器 → Coolify Project 组 → 部署 → 访问点；同一 Project 在不同主机上的部署使用不同分支。项目组以卡片呈现，不再铺成长条容器。
- 仓库是部署卡片的来源属性，默认不显示独立仓库节点。“显示仓库相关性”按明确的 Git 远端标识或本地仓库身份显示跨分支无向虚线。不同主机名的同名仓库不合并，不推断无主机信息的 owner/repo；多个分支使用 n-1 条代表关联，避免两两连线。
- 视图不删除仓库、部署、主机或访问点关系事实；多主机和共享访问点保持唯一资源身份。树状视图和相关性开关可保存、导出、重新打开。独立文件中不直接创建新树状副本，入口提示切回本机白板；已保存的树状文件可正常显示和编辑。
- 缩放范围从交互的 25%–250% 扩大到 5%–800%，保存模型、滚轮、按钮与适合内容使用一致边界；保留鼠标锚点。缩小时背景网格按倍数疏化，不改变实际网格吸附坐标。
- 连线端口弯曲控制点限制在局部范围。密集卡片挡路时，先寻找安全通道，再跨空白区拉直并圆滑转角；不会为了避障生成随两端距离膨胀的巨大弧圈。
- 延续 alpha.38 的群组属性展开、名称编辑修复。

## 参考与边界

参考 [Obsidian Canvas 官方交互说明](https://help.obsidian.md/plugins/canvas) 的端口连接、平移和缩放方式，以及 [JSON Canvas 1.0](https://jsoncanvas.org/spec/1.0/) 独立指定四边连接端口的模型。公开规范未定义其内部避障算法；本实现是 GitFinder 自有的有界路由，不声称复制 Obsidian 内部算法。

## 验证

- 先写回归复现：旧实现的缩放/保存下限为 25%，远距离曲线在 15 卡片场景中会向外绕行 660–1270 像素。
- 浏览器正式控制器：跨组 21 条长连线无无法通行标记，适合内容能降到约 7%；网格仍保持可辨识间距。
- 浏览器正式控制器：创建树状副本、展开两个主机分支、仓库来源属性与相关性开关；开启后出现一条同源虚线，无箭头。
- 自动化：841/841 测试通过；204 个 JavaScript 文件语法检查通过；图标及发布源码门禁通过。
- 回归覆盖：混合端口、局部绕障、15 卡片远距离路线采样不穿卡片、36 部署汇聚、缩放锚点和持久化、原白板保留、多主机及共享访问点、仓库远端规范化、相关性按钮切换与撤销。

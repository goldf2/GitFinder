# 2.0.0-alpha.27 白板快捷工具与可停靠组件

## 已实现

- 根据用户提供的 Lovart 录屏，选中卡片、群组或关系后显示跟随选区的快捷工具条。工具条在屏幕坐标层，保持不透明，不随画布缩放或筛选变淡。
- 多选支持横向/纵向排列、六种对齐及水平/垂直等间距；嵌套群组作为整体移动，不修改关系事实，复用保存与撤销。
- 所选卡片及群组成员可批量展开/收起详情，以及显示/隐藏/继承状态。重命名与属性仍使用已有检查器。
- 快捷工具条、右键菜单及 Delete 支持解散自动 Coolify 群组，保留成员、位置和远端资源。解散状态只保存本机布局，刷新和重新打开不重建组框；撤销可恢复。明确再次执行“自动分组”会重建自动组框。
- 全景导航显示节点缩略图、选中描边及当前视口。支持点击、拖动定位、缩放按钮、100% 和适合全部内容，以及收起导航。
- 双指滚动直接平移视图；Chromium 捏合事件（Ctrl-wheel）围绕手势位置缩放，阻止浏览器整体缩放。鼠标滚轮平移，Ctrl+滚轮缩放；保留 WASD、方向键及 Alt+方向键微调节点。
- 资源库嵌入现有左栏的“白板组件”。资源库、各资源分类/目录组和详情可独立折叠、左右停靠，提供拖动柄和直接换侧按钮。组件可在停靠区排序，已拆出的分类不受资源库折叠影响。
- 详情仍支持固定；组件展开占用布局空间，不覆盖画布。位置、顺序和折叠状态保存为应用本机偏好 `relationshipPanelLayout`，不写入便携项目配置。

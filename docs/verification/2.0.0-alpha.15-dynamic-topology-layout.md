# GitFinder 2.0.0-alpha.15 验证记录

## 交付范围

- Coolify 动态主机、部署和访问端点采用紧凑的关系分组布局，默认每行展示三组“部署 → 访问端点”。
- 动态节点可从卡片空白处直接拖动，关系线在拖动过程中实时跟随。
- 用户调整后的动态节点坐标只保存在 GitFinder 本机偏好中，不写入 Coolify、项目便携配置或关系事实文件。
- 刷新 Coolify 拓扑后继续应用本机坐标覆盖。
- 工具栏增加“自动整理”，用于清除当前白板的动态坐标覆盖并恢复推荐布局。

## 已安装 App 验证

- 安装位置：`/Applications/GitFinder 2 Alpha.app`
- 安装版本：`2.0.0-alpha.15`
- 实际读取：1 台 Coolify 服务器、20 个部署、18 个访问端点。
- 验证动作：
  1. 打开关系白板，确认动态部署与端点不再形成单一超长竖列。
  2. 拖动 `ai-frameflow-saas` 部署卡片，确认卡片 1:1 跟随指针且 `运行于` 关系线同步更新。
  3. 手动刷新 Coolify 动态拓扑，确认拖动后的坐标仍保留。
  4. 点击“自动整理”，确认动态坐标覆盖被清除并恢复紧凑布局。
- 安装包签名：ad-hoc 开发签名；仅用于本机 Alpha 验证，不具备正式分发资格。

## 边界

- Coolify 资源事实仍为只读动态投影；拖动只改变本机显示坐标。
- 动态坐标不参与白板 JSON 导出，因此导入导出仍只携带持久关系事实与白板内容。
- 本次仅验证 macOS arm64 开发包，未重新生成或验证 Windows 产物。

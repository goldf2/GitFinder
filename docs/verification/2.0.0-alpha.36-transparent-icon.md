# alpha.36 透明图标与侧栏精简

## 素材与处理

- 来源：用户提供的 `去除圆角矩形背景的图标.png`，1254 × 1254。原文件没有 Alpha 通道，灰白棋盘格属于图像内容。
- 按用户确认，采用本地像素抠图，没有使用前两次 imagegen 重绘结果。
- 去除主体外部和顶部圆环内部的棋盘格；保留两个下方圆环及箭头周围属于主体的暗色区域。仅对轮廓边缘做抗锯齿与背景去污染。
- 原始下载文件保留。正式资源：`public/icon-master.png`、`public/icon.png`、`public/icon.icns`、`public/icon.ico`。
- ICO 包含 256、128、64、48、32、24、16 像素七种尺寸；ICNS 包含 macOS 标准及 Retina 尺寸。

## 验证

- 浅色、深色背景预览均不再出现棋盘格和圆角底板。
- 源图主体的不透明像素保持原 RGB 值，透明背景和半透明抗锯齿边缘均存在。
- `npm run verify:icons` 通过：PNG 尺寸、RGBA、透明背景和顶部圆环透明区域；ICO/ICNS 格式正确。
- Windows 平台测试 5 项、发布门禁测试 13 项通过；发布源码门禁通过。
- `package.json` 与锁文件同步为 `2.0.0-alpha.36`。

## 资源库行高与入口精简

- 原资源条目最小行高 43px、26px 图标，白板文件按钮额外叠加内边距且继承 17px 字体，造成明显偏松的资源列表。
- 统一资源条目为 32px 最小行高、22px 图标；名称 12px/16px 行高，次要信息 9px/12px 行高，保留单行省略。白板文件采用相同密度，未修改白板画布卡片尺寸。
- 按用户确认移除独立收藏夹、文件标签的侧栏、操作菜单、右键菜单、详情和设置入口；不做标签数据迁移，不新增置顶。保留仓库标签与白板元素标签；本次没有删除既有后端接口或用户文件。
- 先增加回归断言并观察失败，再修复；`npm run check`：818 项通过，0 失败，202 个 JavaScript 文件语法检查通过。
- 浏览器使用生产 HTML、CSS 和控制器的隔离数据夹具，实测项目、仓库、白板文件行高均为 32 CSS px，无文字裁切；项目移到右侧后仍为 32px，已检查截图。
- 以上是源码测试与浏览器夹具验证，不等同于用户已确认安装版效果；待用户确认后再归档问题修复报告。

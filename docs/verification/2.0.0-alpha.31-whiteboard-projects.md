# 2.0.0-alpha.31 白板项目与本地仓库联动

日期：2026-08-31。

## 已实现

- 显式新建白板、独立文档标签页、资源库文件入口；新白板保存为项目目录。
- 文件复制（默认）或引用，项目内媒体使用相对路径；缺失/未授权资源保持占位。
- 文字、图片、文件附件编辑与尺寸调整；附件定位，不包含视频播放功能。
- 群组拖动从实际显示位置起算；点击微移不触发吸附；分组隔离避让；整理基于实际矩形尺寸打包。
- 滚动输入合帧；触控板跟手，离散滚轮平滑收敛；减少动态效果时即时移动。
- 图标工具条配悬停名称，显示面板增加统一卡片宽度和最小高度，详情按内容增高。
- 扫描受管目录后合并仓库索引并重新匹配部署，不删除离线位置旧记录。
- 简略部署卡片显示最近部署 SHA 与本地关联信号；详情显示完整 SHA、最近部署结果、本机路径、打开目录和白板定位。

## 已验证：源码与隔离预览

- `npm run check`：794 项测试通过，198 个 JavaScript 文件语法检查通过。
- 新增覆盖项目媒体随目录移动、复制/引用、外部引用授权、文件冲突、作用域隔离、拖动阈值、平滑滚动和全局尺寸。
- 新增覆盖受管扫描/离线保留/合并索引、部署 SHA 来源、关联状态与路径跳转。
- 兼容 Coolify 部署历史 `{ count, deployments }` 返回结构；优先使用完整 Git URL 匹配，移除地址中的凭据；仍无法确定主机的 `owner/repo` 只作候选。
- 正式组件浏览器预览：宽高从 280×165 调整为 400×240，保存后重新打开仍为 400×240；文字保持原尺寸。
- 仓库预览：扫描前两个部署均“未发现本地仓库”；扫描后均“已关联本地”，同一个仓库生成两条部署来源关系。
- 多副本场景均显示“待确认 2”，未擅自建立唯一绑定。
- 点击关联信号展开完整仓库路径；跳转回调收到正确目录。该预览使用模拟文件系统，不能代替本机操作验收。

## 范围与剩余限制

- 不内嵌播放音视频；不提供云端同步或媒体打包导出。
- 扫描不读取系统钥匙串、不访问远程 Git、不改工作区文件。
- 提交未知保持未知；最近失败部署的 SHA 与当前运行版本不能画等号。
- 未提交或推送 Git，保留工作区原有未提交修改。构建为本机 ad-hoc 开发包，不是公证正式发布包。
- 用户确认问题已修复后，再依项目规则归档修复报告。

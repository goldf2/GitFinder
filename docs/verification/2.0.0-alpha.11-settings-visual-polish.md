# GitFinder 2.0.0-alpha.11 设置页视觉优化

## 交付范围

- 右侧设置分类内容限制为 860 px，避免宽屏表单被过度拉伸。
- Panel 设置拆分为“已添加的 Panel”和“添加或更新连接”两张独立卡片。
- Panel 表单使用稳定的标签列与 280–420 px 输入列，文本框占满输入列并统一边框、圆角、背景和聚焦状态。
- 空状态、安全说明、验证操作建立明确层级；安全说明改为可见的信息卡片。
- 移除页头重复且语义不准确的“完成”按钮，保留底部“取消 / 保存设置”。
- 左侧分类图标使用克制的分类色，当前分类使用实色图标强化位置感。
- 920 px 以下自动切换为单列表单，保持窄窗口可读性。

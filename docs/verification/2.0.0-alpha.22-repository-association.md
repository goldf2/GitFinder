# 2.0.0-alpha.22 部署与本地仓库自动关联

## 范围与规则

- 比较 Coolify 源码地址与已注册本地仓库的当前 origin；统一 SSH/HTTPS、标准端口及 `.git` 后缀。
- 唯一匹配自动连线；多个本地副本需确认。缺少 Git 主机的 `owner/repo` 只提供候选，不推断托管平台。名称相似、镜像名称和分支不能独立触发关联。
- 优先级：项目中保存的绑定 > 本机手工选择或暂停 > 自动匹配。项目绑定仍在项目详情中管理。
- 支持选择 1–8 个仓库、解除关联、恢复自动匹配。解除后刷新不会重连。
- 本机手工/暂停偏好保存于应用数据目录 `coolify-repository-associations.json`，仅含 provider/resource/repository ID 和模式；不含凭据、路径或源码 URL。
- 不初始化项目、不执行 Git 写操作、不修改 Coolify。后台只读取已注册根目录的 origin，不递归扫描、不 fetch、不访问钥匙串。
- 保持既有卡片样式、图标及布局偏好；工具栏图标化不在本次范围。

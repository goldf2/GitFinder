# 2.0.0-alpha.46 下级链接联动拖动

## 功能边界

- 单选节点或群组后的快捷工具条提供链条图标「锁定下级链接」，蓝色按下状态表示开启；默认关闭。
- 开启后沿有方向的下级关系移动，主机包含项目容器、部署及访问点，群组递归包含嵌套成员。共享下级只移动一次，不沿仓库相关性或无方向关联拉动其他上级。
- 仓库来源、运行于、访问点等反向事实转换为下级方向；不改变 Coolify 或 Git 的关系事实。
- 锁定只控制拖动及 Alt/Option+方向键微调；显示/展开等操作不会扩展到下级。
- 拖动完整容器保留自动排列。单独拖动容器内的联动分支时，所在自动容器固定当前几何并切为手动，提示用户，可撤销恢复。
- 不自动更换联动分支的群组归属。任一下级或其祖先容器已锁定位置时，阻止整支移动并提示。
- `moveWithDescendants` 是当前白板的卡片配置，支持动态布局保存、严格文件导入导出、撤销重做；旧文件默认关闭。

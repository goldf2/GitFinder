# 2.0.0-alpha.24 群组交互

## 实现范围

- 沿用 Shift 拖框多选，点击“群组”或 Cmd/Ctrl+G 建组；单击群组的编辑图标可改名。
- 卡片或群组拖入另一个群组时，高亮目标边框；松手归入最内层命中群组，拖出其原始范围解除归属。拖动期间目标边框不随成员扩张，松手后才重新包围成员。
- 允许嵌套，禁止加入自身、子孙群组及循环引用；拖动父群组递归移动全部成员，每个元素只移动一次。
- 群组名称、背景色、描边色和上级群组可在详情面板保存；背景使用浅色透明叠色，选中描边不覆盖自定义颜色。
- 本地和 Coolify 动态卡片均可归组；动态归属沿用本机布局配置，不修改远端资源，不把动态资源变成静态事实。
- 群组操作支持撤销/重做；删除群组保留成员卡片与子群组。导入新白板及导出保留嵌套、配色，既有白板导入继续保留本机布局优先策略。
- 框选组内卡片时，不会仅因触及父群组背景便把父群组一并选中；需要完整包围群组才会选中该群组。
- 选中卡片与群组使用 2px 实线外描边，与筛选光晕区分；低可视卡片选中时恢复可视度。
- Shift 在非输入区域按下时，画布空白处显示十字框选光标；框选过程中保持，松键或失焦恢复，窗口失焦取消未完成框选。
- 保留 alpha.23 的 WASD/方向键平移、Shift 加速、Ctrl 双指平移及 Alt/Option+方向键微调。

# GitFinder 2.0.0-alpha.16 验证记录

## 实际范围

- 关系白板新增智能对齐、24 px 网格吸附和关闭吸附三种模式；拖动时显示参考线，按住 Option/Alt 可临时关闭。
- 多选节点可从工具栏或 Cmd/Ctrl+G 建立视觉分组，Shift+Cmd/Ctrl+G 可移出分组。
- 每个白板节点可保存标签、可折叠备注、待办、截止时间和提醒时间。
- 筛选器可按标签、有备注、有待办、未完成、已逾期、今天截止、今天提醒和已完成筛选，并保留一跳关系上下文。
- Coolify 动态节点的注释只写入本机 `relationshipDynamicLayouts`；Coolify 事实仍保持只读。
- 已保存的 Coolify 连接可编辑名称或地址。只改名称时复用 App 会话；改地址时先验证成功再替换。

## 边界

- 当前提醒是 GitFinder 运行期间的应用内提醒，不是系统后台推送；应用退出或电脑休眠时不会独立执行。
- 视觉分组、标签、备注和待办属于白板布局元数据，不参与 Git 或部署事实推理，也不会触发 stage、commit、部署或服务器写操作。
- 本记录不代表 Windows 真实运行时验证；Windows 仍需由 Windows CI/真实虚拟机生成并验证对应产物。

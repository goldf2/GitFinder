## 工具栏闪烁反馈与修复

用户录屏：`录屏2026-08-31 19.13.02.mov`，15.27 秒。缩放期间可见工具栏整块短暂缺失，随后恢复；同时检测数量、保存提示持续更新。

- 可复现的布局抖动：访问点检测按钮正文随计数改变宽度，保存提示宽度也不固定。窄工具栏处在换行边界时，状态更新会移动后续按钮和画布边界。
- 绘制稳定性处理：去掉每张卡片永久的 `will-change: transform`；画布使用限定可视区域的独立绘制/合成层，工具栏保持不透明且不参与 flex 收缩。此项针对录屏中的短暂缺帧，不以 DOM 几何测试冒充像素级证明。
- 检测数量仍通过悬停提示与可访问名称显示；检测状态不再改变图标按钮尺寸。保存状态保留固定宽度。

# 2.0.0-alpha.26 自动分组、群组拖动与中心布局

## 范围

- 白板工具栏增加独立的“自动分组”按钮，位于“自动整理”旁；空白右键菜单提供“自动分组（Coolify Projects）”。
- 两个入口复用已有 Coolify Projects 分组操作，无须先改变“布局方式”，已处于项目分组时也可再次执行。
- 仍按 Coolify 实例和项目 UUID 归组；共用主机和跨项目资源保留唯一节点及跨组连线。无部署数据时提示连接 Coolify，不改动白板。
- 复用原有保存与撤销/重做，不增加远端写操作，也不改变既有手工群组和卡片注释的存储方式。
- 修复自动群组拖动：原逻辑仅从持久实体查找群组，遗漏动态生成的群组，导致只移动外框而未移动成员；现从合并实体集递归查找，支持整体拖动与嵌套成员。
- 布局方式新增“围绕我（选中卡片）”和“服务器为中心”；单卡右键可选“围绕我布局”。按图关系距离分环，多服务器采用最近中心归属，共享节点不复制；未关联节点独立排放，不创建推断关系。
- 手工嵌套群组按整体边界参与中心布局，成员使用相同位移，保留组内相对位置；中心布局保存坐标并支持撤销/重做。
- 环形按卡片宽高比例排列、错开层级角度，并在适合画布时计算展开卡片及群组的实际边界。

## 验证

- `npm run check`：756 项测试通过，194 个 JavaScript 文件语法检查通过。
- 新增回归：工具栏/右键入口、重复执行无重复节点或关系、手工群组与备注/别名保留、未连接时不改变布局或历史。
- 正式控制器隔离页面：从未连接状态点击会提示；载入两个 Coolify 项目后点击按钮显示两个项目组和一个共享资源组；重复执行节点总数保持 13；撤销回到未分组状态，重做恢复分组。
- 新增回归复现自动群组遗漏成员的拖动错误；中心布局覆盖多服务器、共用部署、循环关系、多访问点、矩形避让、中心保留、手工嵌套群组及保存/撤销。
- 浏览器实际切换服务器中心布局及卡片右键“围绕我布局”：10 个原始节点和 5 条关系保留，旧手工群组仍显示。

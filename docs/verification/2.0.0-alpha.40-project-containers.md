# alpha.40 项目容器、布局菜单与部署归档

日期：2026-08-31。

## 实现范围

- “视图与布局”统一菜单：向右树状、向下树状、左右分叉、环绕放射；其它排列与一次性初始化分开列出。布局选项支持键盘导航，菜单在白板可用区域内定位。
- Coolify Project 使用包裹部署的群组容器，不再使用 Project 卡片。显示菜单的“项目组包含访问点”默认开启；共享访问点独立显示，关闭时只包裹部署。四种排列按实际卡片尺寸预留空间，布局偏好可保存。
- 仓库关联操作修复：异步保存标记清除后，同时刷新卡片与详情面板，避免卡片上的按钮持续禁用。取消、手动关联、解除和恢复自动匹配都可继续操作。
- “新标签页打开目录”保留原白板标签；独立系统目录按钮在 macOS 显示“在访达打开”，Windows 显示“在资源管理器打开”。系统打开仍受受管目录权限边界保护。树状视图的“定位关联部署”定位已有部署，不暗中添加仓库节点。
- 卡片详情与右键菜单可归档部署；“视图与布局 → 归档的部署”提供详情与还原。仅作用于当前白板，不改变 Coolify 服务。隐藏独占访问点，保留共享访问点；关系事实不删除。归档保留坐标、别名、备注与待办，并为动态部署保存无会话信息的本地快照。离线快照不冒充当前运行状态。归档可保存到白板文件，并支持撤销和还原。

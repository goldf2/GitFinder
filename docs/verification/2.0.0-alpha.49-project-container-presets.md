# 2.0.0-alpha.49 Project 容器预置与星系走线

## 目标

将白板的三个维度严格分开：

- 逻辑结构决定 Project、部署和访问点的归属与约束；
- 布局决定树状、分列、环绕或项目星系等位置算法；
- 显示只决定容器形状、填充强度和卡片视觉，不改关系事实。

## 本版实现

- 全局 Project 容器预置支持矩形、圆形和多边形。
- 点击单个群组标题后，可在快捷工具条覆盖容器形状，并选择浅色填充、仅描边或强调填充。
- 单容器覆盖保存到白板布局；动态 Coolify Project 覆盖保存到本机动态布局，重新打开仍保留。
- 星系布局按每个 Project 的实际形状计算紧凑边界；圆形和多边形保持等宽高，矩形按内部部署收紧。
- 访问点继续位于 Project 外围，部署保持在 Project 内部；单卡归档后重新排列。
- 非 Project 群组作为完整区域参与整体排列，不拆散共享资源组、手工群组或嵌套群组。
- 星系长连线使用连续三次贝塞尔曲线；连接端点按矩形、圆形或多边形边界选择。
- 卡片仍使用统一圆角矩形和左侧待办识别条，不随 Project 容器形状变化。
- 访问点保留外部打开按钮，并可在卡片与受限网页预览之间切换。

## 自动验证

- 模型验证覆盖单群组形状和显示样式的保存、非法值拒绝以及普通卡片字段隔离。
- 布局验证覆盖三种形状、外围访问点、共享资源、非 Project 群组完整性和重复整理稳定性。

- 路由验证覆盖圆形边界、曲线通道、障碍绕行和远距离连线。

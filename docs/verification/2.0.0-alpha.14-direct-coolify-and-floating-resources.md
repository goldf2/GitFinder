# GitFinder 2.0.0-alpha.14 验证记录

日期：2026-08-29

## 实际交付

- GitFinder 通过 Coolify 官方 `/api/v1` 只读接口直接读取服务器、项目、应用、服务、数据库、部署记录与公开域名，不依赖 Xiangshu Panel 或 `coolify-dashboard` 运行。
- 多个 Coolify 地址及访问令牌保存在 GitFinder 应用自有会话中；项目便携关联只记录稳定 ID，不记录实例地址或令牌。
- 关系白板把 Coolify 动态资源分类为主机、站点与部署、访问端点，并保持“未知部署历史”和“未知延迟”的真实语义。
- 全局左侧导航在文件浏览、设置和关系白板中保持可见。
- 白板资源库改为中央画布上的浮动工具面板：可从工具栏显示或隐藏、可通过标题栏拖动、可用关闭按钮收起，并限制在中央画布范围内，不覆盖右侧属性面板。

# alpha.43–44 群组批量排列与自适应验收

日期：2026-08-31

## 实现

- 顶部“全部自动排列”一次开启当前白板全部未锁定群组，包含嵌套和动态项目组，不受内容筛选限制；再次点击关闭并固定可见位置。锁定祖先或成员的群组跳过。
- 自动容器按内容计算宽高，不再把旧手动尺寸当作不可缩小的下限；手动容器保留指定尺寸。
- 根据用户提供的 Lovart 录屏采用宽度驱动的顺序换行：宽度变窄增加行数，变宽减少行数，成员不缩放，间距跟随显示设置。
- 组内自适应与全板树状、放射等布局独立。全板布局只整体移动群组，保留内部偏移与换行宽度。
- 拖动中边框跟随输入并预览重排，释放后按内容收紧；整个操作一次撤销，动态位置与尺寸保存。

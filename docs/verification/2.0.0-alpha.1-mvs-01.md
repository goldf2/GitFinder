## 已实现并验证

1. 2.0 使用独立包名、Bundle ID、用户数据目录、版本和构建产物名称，不覆盖 GitFinder 1.x。
2. 保留 1.x Finder 式主窗口、侧栏、标签页、目录/项目识别和右侧检查器。
3. 设置页可连接版本化、只读的 Panel Provider；未知主版本或缺少只读能力会被拒绝。
4. Token 通过 Electron `safeStorage` 加密后保存在应用本机数据中；项目便携关联只含稳定 ID。
5. 项目详情可明确选择一个 Panel 资源并写入 `.gitfinder/deployments.json`。
6. 右侧原生部署面板显示资源名称、状态、环境、服务器、域名和观测时间，不嵌入网页。
7. Panel 请求不阻塞本地项目详情；未配置、未关联、加载失败和正常状态相互区分。
8. 关联对话框只通过关闭按钮或 Escape 关闭，点击主窗口其他区域不会误关。

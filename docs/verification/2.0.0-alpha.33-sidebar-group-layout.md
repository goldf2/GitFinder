# alpha.33 侧栏导航与群组排列

日期：2026-08-31

## 已实现

- 应用侧栏增加「项目 / 目录」切换，记住本机选择；不切换中间白板或当前浏览路径。
- 资源库改为「当前白板 / 全部资源」，不再重复目录树；当前白板包含文字、媒体、群组和缺失资源，可搜索和定位。
- 移除外层「白板组件」标题；保留资源分类独立折叠及左右停靠。
- 每个群组标题提供「自动排列」开关。开启后直接成员按群组宽度换行，使用显示设置中的横向/纵向间距；嵌套群组作为整体排列。
- 关闭自动排列时固化当前显示位置。右下角手柄可调整群组宽高；手动模式不会移动成员或自动收缩边框，并限制缩小边界以免裁掉现有成员。
- 群组尺寸与排列方式随白板保存、导入/导出及动态 Coolify 布局保留；支持撤销。锁定成员不被自动移动，筛选隐藏不重新排位。
- 群组标题仍保持屏幕字号，增加最小显示宽度容纳快捷开关。根据 apple-design 交互原则保留缩放下抓取点和取消恢复，未添加动画依赖。

# GitFinder 2.0.0-alpha.18 验证记录

## 实现范围

- 每个关系白板可独立设置卡片大小、文字大小、信息密度、卡片层次、默认标题来源、画布网格、关系文字和服务状态显示。
- 白板级设置只影响当前白板，不修改项目、Git 仓库或 Coolify 资源数据；旧白板读取时自动补齐默认值。
- 单张卡片可覆盖白板的默认标题来源和状态显示，并继续支持保持原名、替换标题、前缀、后缀和副标题五种自定义名称方式。
- 卡片顶部和底部提供详情展开入口，复用原有右侧属性内容并改为浮动详情窗口；固定后点击画布不会自动收回。
- Coolify 服务器和部署卡片增加明确状态徽标，覆盖运行中、部署中、已停止、部署错误、部署失败、故障、离线和状态未知。

## 优先级与数据边界

- 卡片标题来源和状态可见性的优先级为“单卡配置 > 当前白板设置 > 应用默认值”。
- 卡片大小、文字大小、信息密度和视觉层次当前按白板统一设置，避免同一拓扑中节点尺寸失控；后续如需单卡缩放应独立评估连线和自动布局影响。
- 自定义名称、备注和显示覆盖只写入白板布局元数据，不回写 Coolify、项目配置或 Git。
- Coolify 连接保持只读，不会触发部署、重启、停止、服务器写入或 Git 操作。

# alpha.32 仓库扫描与部署匹配

日期：2026-08-31。

## 修改

- 全局磁盘扫描只保留在资源库，明确标为“扫描本地仓库”；保留最近一次扫描的仓库数、已关联、待确认、未匹配和无来源统计。
- 卡片“匹配此部署”使用已扫描索引，不扫描磁盘、不批量读取 origin、不修改其他部署绑定。恢复自动模式是单独动作。
- 候选目录直接显示在详情中，选择后仅保存当前部署的本机关联；源地址缺失、候选歧义、未找到和原目录失效分别提示。
- 优先读取完整 Git URL；GitHub App 短仓库名通过明确的 `source_type`、`source_id` 和 `/github-apps` 的 `html_url` 补全，不默认猜测 github.com；不读取私钥或要求敏感权限。
- 解析 Coolify `{ count, deployments }` 部署历史，卡片显示最近部署提交与结果，不将失败部署误称为当前运行版本。

接口依据：[Coolify GitHub Apps 控制器](https://github.com/coollabsio/coolify/blob/main/app/Http/Controllers/Api/GithubController.php)、[应用模型](https://github.com/coollabsio/coolify/blob/main/app/Models/Application.php)。

# 2.0.0-alpha.25 白板右键菜单与 Coolify Projects 分组

## 实现

- 空白处、卡片、多选卡片、群组、连线提供上下文右键菜单；已选卡片右键不丢失多选。
- 复用属性、显示别名、注释/待办、展开详情、成组/移出群组、解散群组、撤销/重做及手工连线反转/删除操作。
- 动态资源和派生连线保持只读，不提供远端删除、停止、部署等写操作；混合选择不提供部分生效的删除。
- 空白处创建节点以点击位置为起点；菜单不随画布缩放或筛选降低可视度，并约束在窗口内。支持方向键、Home/End 和 Escape；失焦或外部点击关闭。
- 新白板默认按 Coolify Projects 分组；旧白板保持原布局，通过“布局方式”下拉框或空白右键切换。
- 分组键为实例 ID 和项目 UUID，同项目的不同环境合组，同名跨实例不合并。缺失归属标记“未分配项目”。
- 独占的部署、访问点、自动关联仓库在对应项目组内按类别排列；共享主机、跨项目仓库/访问点保留唯一节点和跨组连线，放在共享资源组。
- 既有手工卡片保持位置，自动分组区域避让这些卡片。动态位置、显示别名、注释及组归属继续使用本机布局配置；刷新不覆盖手动位置，新资源自动归组。
- 群组背景位于连线下方，卡片位于连线上方；连线文字也可右键。工具栏布局选择合并为下拉框，窄窗口换行而不是逐字竖排。

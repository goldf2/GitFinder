# 主机、Project 与仓库的联动拖动边界

- 主机开启“固定下级”：关联 Project、容器成员与符合独占/共享条件的访问点一起移动。
- Project 拖动：物理成员随容器移动；开启固定下级时可继续关联部署到访问点。
- 容器内的仓库卡片可以作为成员随容器移动，但它的“部署来源”关系不意味着其全部部署都属于当前主机/Project，不能据此带动其他容器的部署。
- 从仓库本身发起“固定下级”拖动仍可带动它的同源部署；显式多选仓库也保留此能力。
- 来源关系连线不删除，部署归属不修改，已有白板不需要迁移或重新排列。

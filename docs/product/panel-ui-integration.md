# Xiangshu Panel 原生界面整合

- 状态：项目详情、动态白板和应用自有会话首批切片已实现；本地 Mock Panel 与普通 macOS 安装启动已验证；真实 Panel 和 Windows 未验证
- 界面基线：GitFinder 1.x v1.30.13

## 设计结论

GitFinder 2.0 直接复用 1.x 已验证的布局与交互结构。Panel 提供数据，GitFinder 负责用本地原生组件呈现；不复制 Panel 整站，不使用 `iframe` 或 Electron `webview`。

```text
[侧栏]       [工作区标签 / 项目详情]                 [右侧检查器]
位置           项目概要                                选中的部署资源
收藏           Git 仓库                                 服务器 / 环境
项目           部署面板（Panel 数据）                  域名 / 状态 / 时间
智能集合       - 生产  running  example.com             打开 Panel / Coolify
               - 预发  degraded staging.example.com
```

## 对应 1.x 界面结构

| 1.x 结构 | 2.0 整合内容 | 行为 |
| --- | --- | --- |
| 侧栏项目/收藏 | 显示有部署关联的项目状态摘要，可选故障计数 | 不新增一级部署视图；点击仍进入项目 |
| 项目详情 | 新增“部署面板”区块，按环境分组资源 | 展示状态、服务器、域名、观测时间和跳转入口 |
| 右侧检查器 | 选中单个部署资源时显示完整只读事实 | 外部链接需用户点击，不自动打开 |
| 关系白板 | 派生服务器、部署服务、项目、仓库和公开端点关系 | 派生投影不覆盖用户手工布局和事实 |
| 标签页 | “部署面板”可从项目详情打开为项目内工作标签 | 它始终带有项目上下文，不是全局第一级模式 |
| 设置 | 多 Panel Provider、应用会话、通知阈值、冷却和免打扰 | 项目便携配置不保存 Token |

## 部署面板内容层级

1. **连接状态**：Provider 名称、API 版本、最后成功同步时间、快照是否过期。
2. **环境分组**：生产、预发、测试等 Panel 稳定环境身份。
3. **资源行/卡片**：类型、名称、状态、服务器、公开域名、最后观测时间。
4. **事件摘要**：只显示状态变化、故障与恢复，不在 Alpha 做复杂日志分析。
5. **操作**：刷新快照、管理关联、打开 Panel、打开 Coolify。不提供停止、重启、删除或部署。

## 视觉语义

- 沿用 1.x 的间距、字体、按钮、卡片、标签、空状态和深浅主题变量。
- 项目颜色、Git 紫色角标和 Git 综合状态条仍保留原语义。
- 部署状态是新维度，使用独立状态胶囊和文字，不复用 Git 状态横条或项目颜色。
- 快照过期、Provider 断开与资源故障必须视觉分离，不将“暂时无法同步”显示为“服务已下线”。

## 加载与失败边界

- 项目、目录和 Git 本地内容先显示，Panel 请求不阻塞本地页面。
- Panel 数据区块拥有独立加载、空状态、过期快照和错误状态。
- 请求迟到结果不得覆盖新项目或新 Provider 状态。
- 已有本地项目和文件操作在 Panel 断开时继续可用。

## 首批界面验收

- 在没有 Panel 配置时，1.x 已有项目页面保持可用，只显示明确的“连接 Panel”入口。
- 单个项目可显示一个关联资源的环境、服务器、域名、状态和观测时间。
- 选中资源后右侧检查器更新，不破坏项目、文件和 Git 的原有选择语义。
- 不出现 Panel 网页 DOM、登录表单或 Coolify Token 输入于项目便携数据。
- 1024 px 宽度下项目详情和检查器无文字层叠；深浅主题、键盘导航和屏幕阅读标签通过验收。

## 当前实现范围

- 已复用 1.x 窗口、侧栏、目录卡片、项目识别、设置页和右侧检查器。
- 设置页支持多个只读 Panel Provider，每个地址连接时分别校验 API 主版本与只读能力；GitFinder 不读取系统钥匙串或保存密码，只把可撤销只读令牌作为独立应用会话，不写入项目。
- 已在普通项目文件夹与 Git 项目详情中增加独立部署区块，支持未配置、未关联、加载、失败和正常状态。
- 已支持从 Catalog 明确选择一个资源，并将稳定 ID 写入 `.gitfinder/deployments.json`；不触发 Git 或部署写操作。
- 已支持刷新快照及用户点击后打开允许列表中的 Panel/Coolify 链接。
- 已移除 1.x 遗留的白板直连 Coolify、Token 输入和对应 IPC；部署数据统一由 Panel Provider 提供。
- 已在关系白板中加入服务器与部署的只读动态投影，显示当前状态、延迟、更新时间、最近部署失败、分支和部署提交；动态事实不写入持久白板。
- 已支持一个部署显式关联多个 `repositoryId` 并指定主仓库；本地项目扫描在后台继续，不阻塞白板首屏。
- 尚未实现侧栏故障摘要、项目内独立部署标签、SSE 事件摘要与系统通知。
- 真实 Xiangshu Panel 尚未提供本文契约的生产 `/topology` 接口；macOS 当前仍是 ad-hoc 开发签名，不具备正式分发资格，但应用会话不再依赖签名变化敏感的钥匙串访问控制。

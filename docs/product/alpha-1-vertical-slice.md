# GitFinder 2.0 Alpha 1 最小垂直切片

- 目标版本：`2.0.0-alpha.1`
- 当前状态：已设计，未实现，未验证

## 可发布闭环

Alpha 1 的产品闭环包含：

1. 导入或继承现有 GitFinder 本地项目。
2. 连接经过身份验证的 Xiangshu Panel Provider。
3. 由用户将本地项目、可选 Git 仓库与 Panel 项目/环境/资源显式关联。
4. 项目详情显示服务器、环境、域名、部署状态和最后观测时间。
5. 白板投影“服务器 → 部署服务 → 本地项目 → Git 仓库”。
6. GitFinder 消费 Panel 产生的故障/恢复事件，按去重、阈值、冷却和免打扰规则发送 macOS/Windows 系统通知。
7. 点击通知返回对应项目，并可由用户选择打开 Panel/Coolify。

## 最小垂直切片 MVS-01

先只贯通“一个已有项目 + 一个 Panel Provider + 一个部署资源”，但要端到端覆盖身份、关联、显示、白板和通知。不先做大规模列表、批量匹配或管理写操作。

### 实现顺序

1. **项目兼容层**：只读打开 1.x `.gitfinder/project.json`，保持 `projectId` 不变。
2. **Provider 契约层**：用本地假 Panel 服务器先锁定 Catalog/Snapshot/Events/Capabilities 契约，再与真实 Panel API 对接。
3. **安全连接**：Provider 地址与标签保存在本机，Token 写入系统安全凭据存储，日志不输出原始请求。
4. **显式关联**：在 1.x 风格的项目详情中选择一个 Provider 资源，预览差异后确认写入非敏感关联。
5. **项目投影**：在现有项目详情加入原生“部署面板”，右侧检查器显示单资源事实，并在现有白板中建立可追溯派生关系。
6. **事件与通知**：使用 Panel 事件实现故障、去重、冷却、恢复和点击定位。
7. **双平台发布门禁**：在真实 macOS 和 Windows 环境验证安装、连接、关联、项目详情、白板和系统通知。

## 验收标准

### 项目与兼容

- 给定有效 1.x `project.json`，2.0 可只读导入，`projectId`、名称、颜色、生命周期和仓库排除语义不变。
- 导入不执行 `git init`，不自动 stage/commit/push，不改写 1.x 清单。
- 嵌套项目仍截断父项目的仓库扫描。

### Provider 与安全

- 真实 Panel 对接前，Capabilities 与数据契约必须版本化，未知主版本会被拒绝。
- 凭据只有目录、快照和事件读权限，且可撤销。
- Token 不出现在项目目录、便携文件、白板、导出、错误文本、普通日志和崩溃附加信息中。
- GitFinder 只发出契约内 GET/SSE 或等价只读请求，不暴露管理写入入口。
- 过期/撤销凭据、网络断开、返回过大、非 JSON 和契约版本不兼容都会可见失败，且不泄露凭据。

### 关联与显示

- 关联只在用户确认后写入；名称、仓库 URL 或域名只可作为建议，不可自动成为事实。
- 便携关联只包含允许的 Provider/节点/项目/环境/资源稳定 ID。
- 项目详情能显示服务器、环境、域名、状态和带时区的最后观测时间，断网时明确标记快照时间，不冒充实时。
- 白板可从同一关联派生“服务器 → 部署服务 → 本地项目 → Git 仓库”，删除派生投影不删除 Panel 或项目事实。

### 通知与持续监控

- 默认连续 3 次失败后才通知，配置为 2 时依照配置执行。
- 同一事件只通知一次，轮询重放、SSE 重连和应用重启不会重复提醒。
- 故障恢复会发送一次恢复通知，且能追溯原故障。
- 项目、环境、严重程度、冷却和免打扰规则在重启后保留。
- 点击 macOS/Windows 系统通知可定位到对应项目；Panel/Coolify 外部跳转需要明确用户操作。
- 退出 GitFinder 或让电脑休眠后，Panel 端监控仍继续。GitFinder 重开后使用事件游标或快照恢复，不宣称在进程不运行时发送了本机通知。

### 发布与实机验证

- macOS 实机：安装、启动、凭据存储、连接、关联、状态显示、白板、故障/恢复通知和通知点击全部通过。
- Windows x64 真实 runner 与用户虚拟机：安装/卸载、默认启动、Credential Manager、目录/Git 基础、Provider 连接、白板、系统通知和通知点击全部通过。
- 清楚分开“代码已适配”、“产物已构建”、“目标实机已验证”。
- 未签名产物只能标记为测试版，并明示 Gatekeeper/SmartScreen 风险。

## 完成定义

MVS-01 只有在真实 Panel 契约、真实 macOS 和真实 Windows 目标上通过上述验收后，才能从“已实现”进入“已验证”。本地假 Panel 服务器和 CI 单元测试只证明契约与代码路径，不证明生产集成已完成。

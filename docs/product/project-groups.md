# 项目组

项目组是本机项目之上的管理层，用于把多个独立的本地项目归入同一工作主题。项目组不是目录、Git 仓库或关系白板中的运行资源，不会改变项目目录结构。

## 数据边界

- 每个子项目继续由自己的 `.gitfinder/project.json` 标识。
- 项目组仅在 GitFinder 本机配置中保存 `groupId`、名称、说明、颜色和 `projectIds`。
- 一个项目可以加入多个项目组；删除项目组不会删除项目或文件。
- 项目组允许暂时保留找不到的项目 ID，项目重新扫描后会自动恢复显示。

## 使用方式

1. 打开“所有项目”页面。
2. 点击“新建项目组”。
3. 填写组名、说明和颜色，并多选要管理的子项目。
4. 在项目组卡片中可以编辑、删除项目组，或直接打开其中的子项目。

项目组的创建和编辑不执行 `git init`、文件移动、提交或推送。

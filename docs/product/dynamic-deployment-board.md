# 动态部署关系白板

- 状态：客户端首批垂直切片已实现；本地 Mock 与 macOS 安装包已验证；真实 Panel、普通 macOS 更新启动和 Windows 尚未验证
- 产品定位：在 GitFinder 既有关系白板中联动服务器、部署、本地项目与 Git 仓库

## 用户闭环

1. GitFinder 从 Panel 读取动态拓扑。
2. 白板展示服务器和部署资源，节点直接显示状态、延迟、更新时间和最近部署失败。
3. 部署节点通过显式 `repositoryId` 连接一个或多个本地仓库。
4. 用户从异常节点定位到仓库、项目目录和部署提交，进入代码检查。
5. Panel 或 Coolify 的详情页只作为用户主动打开的外部入口；GitFinder 首批不执行运维写操作。

## 首批界面

### 工具栏

- 增加 Panel 动态同步状态与“刷新”按钮；未连接时不生成动态节点。
- 显示连接状态、最后同步时间、资源计数和故障计数。
- 保留现有节点类型、环境、核验状态和部署摘要筛选。

### 服务器节点

- 名称和在线状态。
- 最近延迟。
- 最后观测时间/陈旧提示。
- 部署资源数量。

### 部署节点

- 资源名称、环境和当前状态。
- 访问延迟与探测类型。
- 最近更新时间。
- “最近部署失败：是/否”，失败时间和摘要。
- 已部署分支、提交或镜像版本。
- 本地关联状态：已关联、仓库不在本机、未关联。

### 详情检查器

- 完整显示 Panel 只读事实。
- 列出关联 `repositoryId`、当前解析路径和项目。
- 提供“定位仓库”“在目录中显示”“打开 Panel”“打开 Coolify”等已有安全动作。
- 动态节点不可编辑事实来源、名称或状态；只允许管理本地关联和布局偏好。

## 布局和交互

- 默认按“服务器 → 部署 → 仓库 → 项目”分栏自动布局。
- 动态节点采用确定性 ID，刷新后不跳变。
- Panel 投影与手工节点可同时显示；动态节点使用独立视觉标识和同步状态。
- 用户手工连线不能被轮询删除；Panel 派生连线不可编辑或删除。
- 选择、筛选、缩放、拖动画布沿用现有白板行为。

## 状态表达

| 维度 | 示例 | 视觉职责 |
| --- | --- | --- |
| 当前运行 | running / degraded / stopped | 主状态胶囊 |
| 最近部署 | success / failed | 独立部署结果标记 |
| 延迟 | 32 ms / 未知 | 数值与探测类型 |
| 新鲜度 | 刚刚 / 3 分钟前 / 陈旧 | 时间和警告 |
| 本地关联 | 已解析 / 本机缺失 / 未关联 | 仓库关联提示 |

这些维度不得合并成一条颜色；例如“当前 running + 最近部署 failed + 已恢复”是合法组合。

## 首批垂直切片

1. Panel Provider 增加安全的 `/topology` 读取和严格规范化。
2. `.gitfinder/deployments.json` 升级到 v2 `repositoryIds`，兼容读取 v1。
3. 新增纯函数投影模型，把拓扑与本地项目/仓库注册表组合成只读图。
4. 白板加载/刷新投影，展示服务器、部署及关联线，并提供错误、空、陈旧状态。
5. 本地 Mock Panel 覆盖成功、失败、最近失败、未知延迟和多仓库关联。

## 验收标准

- 没有 Panel 时，白板和本地文件/Git 功能完全可用。
- Mock Panel 返回一个服务器和多个部署时，白板可见动态节点、状态、延迟、时间和最近失败。
- 已绑定 `repositoryId` 的部署连到正确仓库；移动仓库目录后仍可解析；缺失仓库明确提示而不误匹配。
- 刷新动态状态不会改变 `relationship-boards.json`。
- 断线保留最后成功快照并标记陈旧/同步失败，不伪造服务下线。
- 全量测试、语法检查、构建通过，并在实际安装的 macOS App 中验证可见闭环。
- Windows 只能在真实 Windows runner 和虚拟机正常启动/交互后标记为已验证；macOS 构建不能替代这一结论。

## 后续而非首批

- SSE 增量事件、系统故障/恢复通知。
- 提交差异、落后提交数和变更文件跳转。
- 拖动动态节点后的布局覆盖持久化。
- 多 Panel Provider、历史趋势和复杂日志分析。
- 部署、停止、重启、删除等写操作。

## 2026-08-29 验证结论

- Mock Panel 的 1 台服务器、2 个部署和 1 个最近失败已在实际安装的 `2.0.0-alpha.3` 白板中显示。
- 失败部署检查器已显示 `degraded`、环境、服务器、未知延迟、失败时间/摘要、分支和部署提交。
- 手动刷新前后 `relationship-boards.json` 的 SHA-256 未变化，动态拓扑没有写入持久白板。
- 多仓库 `repositoryId` 关联、主仓库约束、仓库移动后稳定解析与缺失提示由自动测试覆盖；本次安装包 Mock 未写入项目关联，因此未把它描述为安装包人工验收。
- 安装包的隔离 Mock 运行闭环通过；不带测试参数的普通启动仍被旧 Safe Storage 钥匙串访问控制阻塞，不能标记为完整 macOS 更新验收。

# Coolify 直接集成

- 状态：只读连接、资源归一化、项目关联与白板投影已实现；真实生产实例和 Windows 尚未验证
- 首个目标版本：`2.0.0-alpha.13`

## 首批用户闭环

1. 在“设置 → Coolify 数据源”添加一个或多个 Coolify 根地址。
2. 输入仅含 `read` 权限的 API Token，验证成功后由 GitFinder 保持本机会话。
3. GitFinder 读取服务器、项目、环境、应用、服务、数据库和应用部署记录。
4. 用户在项目详情中显式选择部署资源并关联一个或多个本地 `repositoryId`。
5. 关系白板按项目、仓库、主机、站点与部署、访问端点分类展示，并生成“仓库 → 部署 → 服务器”的只读动态关系。

## 数据语义

| 字段 | 来源 | 当前语义 |
| --- | --- | --- |
| 运行状态 | Coolify 资源状态 | 当前观测，不替代部署结果 |
| 最近部署失败 | 应用部署记录的最新一条 | 有记录才显示是/否；服务和数据库首批为未知 |
| 服务器可达 | Coolify server settings | `is_reachable` 与 `is_usable` 的只读投影 |
| 延迟 | 无 | 首批显示未知，不使用本机到 Coolify API 的耗时冒充服务器延迟 |
| 最近更新 | 资源 `updated_at` | Coolify 数据更新时间，不等同于最后成功部署时间 |
| 域名 | `fqdn`、`domains` 与 Compose 域名字段 | 用户点击后才通过系统浏览器打开 |

## 安全边界

- 不读取系统钥匙串，不保存用户密码。
- Token 只在主进程使用；渲染层只能取得脱敏连接状态。
- 请求禁止重定向，限制响应大小和超时，实例地址只允许 HTTPS（localhost 例外）。
- 所有 Coolify 操作均为 GET；首批没有写操作入口。
- 外部链接只能打开最近一次受信只读响应中出现的地址。

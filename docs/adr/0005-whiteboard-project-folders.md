# ADR-0005：独立白板项目与本地媒体

- 日期：2026-08-31
- 状态：已实现，验收证据单独记录
- 范围：白板文件与资源，不变更 Coolify 凭据或部署权限

## 决策

每个新白板保存为 `名称.gitfinder-board/` 文件夹，内部 `board.json` 保存一个白板及其元素、关系、位置、展开状态和显示配置；`assets/` 保存复制的图片与文件。旧的单文件 JSON 仍能打开和保存，不自动迁移用户文件。

拖入文件或使用“文件与媒体…”时，先选择复制或引用，默认复制。选择复制不要求原文件属于受管位置，附件使用项目内相对路径。文字直接保存在文档；图片提供预览、尺寸和适配方式编辑；其他媒体当前是附件卡片，不提供内嵌播放或媒体内容编辑。

引用模式保留绝对路径，只有本机明确选择过的路径能被读取。路径授权存在应用本地索引，不随项目导出；另一台设备需重新选择。缺失或未授权的资源显示占位，不删除节点或关系。

独立文件的编辑和撤销历史与本机白板合集隔离。文件保存检查外部修改，冲突时拒绝静默覆盖。新建和另存为不覆盖已有项目目录。资源库移除仅删除记录；移到废纸篓单独确认，项目内复制文件随项目处理，外部引用不受影响。

## 便携性与边界

- 分享、移动或备份时携带整个项目目录。菜单“导出 JSON”只导出文档，不是含媒体的压缩包。
- 本地仓库仍使用稳定仓库 ID 关联，详情中的路径来自本机注册表，不把机器路径当作跨设备身份。
- 仓库扫描只遍历已添加的受管位置，跳过隐藏目录、依赖目录和已发现仓库内部；结果合并到索引，不因离线磁盘归档旧记录。
- 部署根据标准化源码地址关联仓库，唯一候选自动关联，多候选确认；手工关联和主动解除优先。
- 提交 SHA 优先来自最近一次部署记录，同时显示该次部署结果。失败部署的 SHA 不代表当前正在运行的版本；只有配置引用时不伪装成已部署 SHA。
- 不实现云同步、凭据同步、Git fetch/push、部署写操作或系统钥匙串读取。

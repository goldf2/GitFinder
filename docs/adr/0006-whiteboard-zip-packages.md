# 白板便携包：标准 ZIP，文件夹仍是工作格式

状态：用户批准，alpha.35 实现。

- 默认工作格式仍为 `名称.gitfinder-board/board.json` 和 `assets/`。
- 新增 `.gfb` 便携包，内部为标准 ZIP。压缩工具可打开，必要时将副本扩展名改为 `.zip`。
- 导出当前白板及其实际引用的附件，不递归打包整个目录、Git 仓库或应用配置。JSON 继续沿用现有版本信封；不包含应用会话或授权记录。
- 外部引用存在时弹出选择，默认收集已授权附件；也可保留引用或取消。保留引用会保留路径，但不会给予导入设备读取权限。
- 资源缺失或未授权时保留元素和关系，并提示缺失，不影响白板打开。
- 导入选择新的工作文件夹，校验后加入资源库。不直接编辑 ZIP，不自动迁移旧白板，不覆盖已有项目。
- 流式读写附件；JSON 最大 32 MB、单附件最大 512 MB、展开总量最大 2 GB。校验路径、重复文件、符号链接、大小和 ZIP CRC，拒绝白板 JSON 中疑似凭据内容及未关联附件。用户主动添加的附件按其选择携带，不宣称检查过任意媒体文件中的秘密。
- `.gfb` 是专用文件格式，不是加密容器；需要保密的白板应通过受信渠道传递。

ZIP 实现依据：[yauzl](https://github.com/thejoshwolfe/yauzl)、[yazl](https://github.com/thejoshwolfe/yazl) 官方接口。ZIP 本身不提供自动云同步或冲突合并。

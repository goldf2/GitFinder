# ADR-0010：在线更新必须由用户控制

- 状态：已接受
- 日期：2026-09-04

## 背景

GitFinder 2 已接入 `electron-updater`，但启动检查没有用户级开关，下载后的退出安装策略也不够明确。用户需要能够关闭启动联网检查，并在任何下载和安装动作前作出决定。

## 决策

- `config.json` 保存 `automaticUpdateChecks`，默认值为 `true`。
- 开关只控制启动后延迟检查；关闭时，菜单和设置页中的手动检查仍可用。
- 启动延迟结束时再次读取偏好，避免等待期间关闭开关后仍然联网。
- 检查只读取版本清单，不自动下载。
- 发现新版本后，用户点击更新按钮还必须在系统确认框中确认，才开始下载。
- 下载完成后不在退出应用时静默安装；用户可以立即重启安装，也可以稍后从设置页明确触发。
- 系统通知只用于提示和定位到设置页，不代表用户同意下载或安装。

## 结果

自动检查、手动检查、下载和安装成为四个独立动作。环境变量只能关闭整个更新能力或覆盖测试源，不能替代用户偏好。

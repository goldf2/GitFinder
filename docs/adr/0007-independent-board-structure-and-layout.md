# 白板逻辑结构与空间布局分离

日期：2026-08-31

## 决策

白板的组织结构和摆放方式是两个独立维度，分别提供“结构”和“布局”菜单。

- `view.structure`：`resources`（资源关系）、`coolify-projects`（Coolify 项目分组）、`server-tree`（服务器项目树）。决定来源事实如何投影、项目容器的成员以及仓库是否作为关联属性展示。
- `view.layout`：`free`、`compact`、`lanes`、`right`、`down`、`bilateral`、`radial`。只决定现有可见元素的坐标、方向和容器边界。
- `groupId` 是成员关系，不是布局计算的输出。手工嵌套群组、别名、备注、待办、归档和源关系独立保留。
- “项目组包含访问点”属于结构配置。共享访问点保持唯一，仓库相关性仍是可选关联线。

## 操作约定

选择布局立即排列当前白板，不生成副本、不重新读取或重建 Coolify 分组。自由摆放只保存当前位置；“整理布局”是一次性操作，自由摆放时按紧凑方式整理。

切换结构保留所选布局，并用新成员重新应用该布局；新容器默认按内容尺寸自动排列，避免包裹散落的旧坐标形成重叠巨框。只有“自由摆放”保留原可见坐标，新容器以手动模式包裹原位置。已有手工群组不被替换，内部相对位置不变。后台刷新不重新排列。

群组内部自适应独立于全板布局：自动群组按容器宽度、拓扑与位置顺序和显示间距换行，不缩放成员。全板布局把群组视为整体移动，保留其内部偏移与换行宽度。拖动自动容器时边框跟随鼠标并即时重排，松手后按内容收紧；手动群组保留用户设置的尺寸。全局操作跳过锁定群组与锁定成员，关闭时固定可见位置，一次操作可撤销。

保存的白板文件使用已有成员结构，不从实时 Coolify 数据覆盖文档内容。结构、布局均可保存及撤销。

“全部自动排列”开启时，先收紧各组，再应用当前全板布局整理容器（自由摆放除外）；关闭时保留当前画面。分叉和环绕采用稳定分支次序，多棵独立树使用稳定打包顺序，重复点击不换位。缩小到 50% 以下时保留固定字号的组标题，按容器可见宽度省略，并收起组头内联操作；点击标题仍显示完整快捷工具条。

## 旧数据

读取旧 `topologyLayout` / `treeLayout`，只映射设置，不在载入时重新排列或创建白板：

| 旧设置 | 结构 | 布局 |
| --- | --- | --- |
| lanes | resources | lanes |
| coolify-projects | coolify-projects | compact |
| server-tree | server-tree | 原 treeLayout，缺省 right |
| server-centered / selection-centered | resources | radial |

新保存数据只写独立字段。旧版本应用不支持新字段，不能用旧版本编辑新保存的白板文件。

## 验证

`test/relationship-structure-layout.test.js` 覆盖三种结构与七种布局组合、同一白板身份、成员和注释保持、后台刷新、导出重开、撤销重做、归档、可见坐标与锁定/手工群组。

浏览器夹具 `scripts/visual-fixtures/relationship-groups.html` 使用正式控制器及内存数据：1 台主机、4 个项目、12 个部署、13 个访问点。此验证不等同于重新打包安装后的原生应用验收。

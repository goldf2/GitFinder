## 当前基线与范围

本轮采用只读运行时适配：项目里的 `management/development-tasks.json` 或 `docs/00-handoff/TASKS.json` 仍是唯一事实源；GitFinder在受管目录内发现、校验并映射为现有任务视图。无需创建第二份CSV、导出JSON或修改商城代码。旧Local Project Manager在没有仓库台账的项目中保留。

同一项目有两个候选台账时不猜测谁权威；损坏或不支持的台账显式报告，不借旧投影/控制CSV假装正常。保留原始状态、负责人、阻塞、下一动作、依赖、验收条件和证据引用；代码已验证、任务已交付与真实用户确认不混并。完成任务计数不代表产品完成率。

仓库台账任务在App只读：不提供绕过项目校验的状态写回，不通过LPM适配器修改它们。用户/AI在仓库维护台账，App刷新读取；只有LPM权威项目继续使用现有预览/确认写回路径。

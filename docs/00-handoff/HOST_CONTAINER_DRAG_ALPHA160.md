# alpha.160 · 主机容器拖动

## 变更

- 主机容器从只读边界改为可拖动的视图节点。
- 拖动主机容器会联动移动其中的 Project 和未分类部署；Project 内部署仍跟随其父容器。
- 容器拖动只保存成员的白板位置，不保存容器虚拟节点，不改变主机、部署、Project 的事实关系。
- 容器标题继续可点击打开主机显示设置。

## 验证

- 适配器回归覆盖主机容器可拖动、成员联动、空主机容器和原始主机 placement 不变。
- alpha.160 已打包并安装；重启后 AX 确认版本为 `2.0.0-alpha.160`，白板仅显示 AL02、AL03、con01 主机容器，未恢复服务器机架卡片。拖动联动由适配器回归覆盖。

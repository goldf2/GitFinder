# alpha.188 · 白板全屏与重绘生命周期修复

编号：GF-LIFECYCLE-20260915-01。时间：2026-09-15 +08:00。

## 范围与根因

本轮审查 `/Volumes/project/项目/gitfinder-2`，从 alpha.187 的已知全屏遗留问题切入。`render()` 原先替换整个 workspace，导致 fullscreen 根节点被移除、全屏退出和挂在其内的模态窗口丢失。资源库停靠始终选择全屏之外的外部侧栏。直接保留根节点又会使匿名事件监听器在每次绑定时累积，因此事件幂等是此修复的必要组成部分，不代表旧版正常渲染已出现重复点击。

## 实现

- 在临时 template 中构建下一版内容，保留已连接的 workspace 根节点。
- 重绘仅替换工作区内容，保留已打开的模态窗口及其输入/焦点/选区；显示设置保留原有节点和滚动状态，并恢复焦点。
- 使用已有稳定事件委托引用，重复绑定时先移除同一监听器，防止一次点击触发多次动作。
- 全屏进入/退出时重新停靠资源库；全屏内采用内部左停靠，退出后恢复外部侧栏，未保存或改写用户停靠偏好。
- 保持白板事实、布局、数据库和远端写操作不变。

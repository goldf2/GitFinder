# alpha.193 · 布局选项与均衡总览

编号：GF-LAYOUT-OPTIONS-20260916-01。日期：2026-09-16 +08:00。

## 用户需求与范围

用户两张截图显示主机 Project 纵列高度悬殊，con01 过长使全图卡片很小，布局菜单又长且缺乏分组。本轮基于媒体修复提交 `6331df8` 优化布局；alpha.192 尚未安装或推送，计划在包含其媒体修复的 alpha.193 中联合验收，避免重复替换应用。

不自动切换用户已有白板，不修改节点、连线、主机归属或项目成员。不迁移数据库，不执行服务器写操作。用户可主动选择“布局 → 均衡总览”，保留自由摆放与主机纵列。

## 实现

- 新增持久化选项 `project-balanced`（均衡总览）：同一主机下 Project 多列排列，主机整体按可用画布比例均衡摆放，小主机可叠放在较大主机旁。完整群组作为布局单位，不复制资源。
- 原 Project 纵向列表更名“主机纵列”，仍保持原行为；全部10个选项按“常用排列 / 关系走向 / 其他布局”分组，均衡总览标推荐。
- 菜单桌面双列、窄窗口单列；不透明背景、固定标题、简化图标和说明，菜单宽度受工作区约束；支持方向键、Home/End、Esc，菜单快捷键不误操作画布。
- 保留锁定组与手动组边界。均衡/自由模式退出旧的强制纵列修正，避免用户选择均衡后又被显示层改回单列。
- 统一物理 Project 标题保留空间，保存最终显示几何；解决后台刷新/重开时由估算尺寸与显示尺寸差异引起的漂移。
- 主机整体打包预留外框两侧72px、顶部88px/底部64px空间，避免原碰撞修正把叠放的小主机再次挤成超宽横排。

- 使用只读拓扑缓存中3台主机、12个Project、35个部署的脱敏副本，替换所有外部URL及标识，不复制凭据、不访问服务器。全图前后同一画布下，显示包围高度从4142降至2404，宽度从3344变为4328，适合画布缩放从0.117576提高到0.152726，卡片线性显示比例约提高29.9%。这是该夹具的几何/显示效果，不是帧率或全场景性能承诺。

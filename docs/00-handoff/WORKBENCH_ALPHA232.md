# alpha.232 开发工作台

## 范围与依据

用户要求按项目规划、开发执行、测试验收、版本交付、维护迭代组织仓库工作区，优先制定文档结构。设计审阅稿见 [开发文档体系](../product/development-documentation-standard-v0.1.md)（另有同名 PDF）；文档为设计审阅稿；本轮实现了下述本地工作流和跨项目汇总，外部自动化接入仍是后续建议。基线192eef6，原12项未提交路径保持。

## 当前实现

- 单击仓库/项目在列表中选中并预览，进入工作区按钮或双击才进入完整页面。工作区右侧资料默认收起，可手动打开；列表和工作区分别保留显示状态，返回恢复筛选、选中和滚动位置。
- 全局总览与全部项目任务直接汇总原台账，按待推进、阻塞、逾期和待验收展示；可定位具体任务，编辑保存后返回全局刷新。默认测试开关仍关闭，用户明确点击入口后开启。
- 文档分类与标题读取、搜索、阶段模板、内部 Markdown 阅读和编辑；优先复用已有同名文件，不迁移目录。只写用户保存的文件，外部修改冲突保留草稿；AGENTS 与生成的 PROGRESS 只读。
- 当前仓库本地任务独立读取，不再等待全项目关联查询；状态筛选、创建/编辑、验收与依赖/资料分组，保留原台账未知字段，冲突检测、无效台账明确报错。
- 会话列表与本地存档正文并列；外部继续显式操作。代码变更与提交分区；文件页保持原有浏览器。总览提供起步说明。
- 版本交付文档可编辑；GitHub 构建与发布为显式外部查看入口，不把本地记录、提交或构建当作生产发布成功。未执行远端发布操作。
- 合并alpha231标题栏/工具条分离。版本alpha232。

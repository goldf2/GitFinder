## 行为与实现

- 设置 → 测试功能：仪表盘、开发进度（开发任务）两个独立开关，默认关闭；使用现有设置样式、键盘导航与开关控件。即时保存，测试分类不显示其他设置的取消/保存按钮，避免误解。
- 本机 `config.json` 的 `experimentalFeatures` 保存两个严格布尔值。缺失/旧配置/错误类型一律关闭；使用专门受信IPC更新单个开关，合并最新配置，磁盘失败恢复内存并显示错误；不写项目台账或白板。
- 工具栏及系统菜单默认隐藏相应项，路由/直接页面调用再次检查；旧活动/非活动/已关闭标签以及分离窗口恢复时回到文件浏览，保留ID、路径和历史，不删除标签数据。
- 跨窗口同步开关。禁用当前页时回到文件浏览；仅恢复入口，不因重新启用就强制打开测试页。只开仪表盘时任务下钻不可用，不隐式开启开发任务。
- 停止相关15秒轮询及focus监听；隐藏/编辑/无变化的既有刷新约束保留。请求代次丢弃关闭或重启用前的迟到结果，避免回填旧缓存或重新打开页面。
- 主进程全关时不扫描进度台账；只有仪表盘开启时允许读取汇总，不允许开发任务的Git证据和写回操作。已经开始的IO不声称可强制撤销，但关闭后的结果不再作为可用投影返回。
- 已有项目文件、management台账、Markdown生成看板及人/AI接续协议继续使用。隐藏App界面不是关闭项目内工程进度记录。

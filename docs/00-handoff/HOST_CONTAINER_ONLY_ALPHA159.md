# alpha.159 · 主机仅容器显示

## 变更

- 服务器项目树中移除单独的主机卡片，主机只以只读容器边界呈现。
- 容器标题显示主机名和成员摘要；标题可点击打开主机显示设置，不再依赖主机图标卡片。
- 有 Project 的主机包裹 Project；只有未分类部署的主机包裹未分类部署；没有成员的主机仍保留最小空容器。
- 容器边界随 Project 或部署移动而刷新；原始主机 placement、事实关系和 Project 对部署的物理归属不写回改变。
- 仅隐藏视图层的主机摘要边和悬空主机边，部署到访问点等实际关系保持原样。

# alpha.140 项目详情与统一页签样式

2026-09-10 +0800。

目标：解决项目页仍为居中占位、正文信息缺失及左右页签风格不一致。用户截图为问题证据，alpha.139 的交互通过不代表正文体验完整。

实现：项目详情复用 Git 详情头部结构，顶部对齐，分区显示简介、内部仓库、直接子项目、部署关联。信息来自现有扫描元数据，子项目复用最近目录父级规则；仓库与子项目提供本地入口。空选择和普通文件保留原空状态。左右页签共享现有 Apple 分段控件声明及交互样式，无新的主题体系或动画依赖。

范围：使用 apple-design 的一致性原则和 stop-that-shit 的局部修改约束；不修改项目身份、分类、文件布局、Git 内容及远程服务配置。

# alpha.233 界面规范与布局优化

## 目的与范围

用户反馈 alpha.232 虽具备功能分区，界面统一性、信息结构与日常操作仍粗糙。本轮在基线64e5df9上统一框架、集合浏览/摘要预览和开发工作区，保留仓库优先、可选项目属性、单击预览/明确进入、返回恢复的既定逻辑。原12项未提交路径保持，数据归属与远端操作范围不变。

## 参考与落实

参考的是各产品的信息层级与操作组织，未复制其品牌或页面：

- [Apple 工具条](https://developer.apple.com/design/human-interface-guidelines/toolbars)：标题承载位置，工具条放常用操作；统一控件高度与间距，次要选项渐进展开。
- [VS Code 侧栏](https://code.visualstudio.com/api/ux-guidelines/sidebars)：导航、工作正文与辅助信息各有明确区域。
- [Linear 界面改版](https://linear.app/now/how-we-redesigned-the-linear-ui)：减少视觉噪音，增强层级和密度。
- [Jira 新导航](https://support.atlassian.com/jira-software-cloud/docs/what-is-the-new-navigation-in-jira/)、[概览](https://support.atlassian.com/jira-software-cloud/docs/what-is-the-summary-view/)、[显示控制](https://support.atlassian.com/jira-software-cloud/docs/customize-your-view-of-the-board-and-backlog/)：全局范围、项目范围、事项详情分层；任务列表与详情共享事实，筛选与显示设置分开。

具体规范：4/8/12/16/20/24px间距；正文13px、辅助11–12px、工作区标题17px；常规控件30px；中性色表面、弱分隔线；蓝色主要用于操作、选中与焦点；状态同时有文字。遵循系统亮暗模式和减少动态效果设置。此为本轮界面规范，不声明完整无障碍认证或商业发行就绪。

## 实现

1. 标题栏36px、工具条44px、工作标签32px。仓库筛选合并到一行，复杂条件移入筛选面板；小窗口显示菜单可滚动，不越出窗口。
2. 仓库卡片去除重阴影和装饰色带，统一标题、两行简介、状态/最近提交与底部入口。多标签显示3项与剩余计数；键盘焦点与选中区别清楚。
3. 右侧快速预览显示简介、真实Git状态、最近提交、属性标签与路径，提供进入工作区、访达与少量资料入口。预览不再等待完整文档、任务及架构读取；完整编辑在工作区。
4. 总览突出进行中、待验收/交付、受阻、当前分支和下一任务。文档/任务/会话/记录共享列表与阅读编辑区；保存操作固定，长表单滚动导航预留保存条空间。全局任务统一筛选条和结构化详情，仍读原任务台账。
5. 修复实际验收发现的状态错位：全局data-path匹配会先命中侧栏，主卡片停留占位状态。更新限定主区，批次完成刷新卡片数据；读取前显示“读取中”，不假定干净或未提交；保留状态文字。分支读取失败、普通目录与尚无提交分开。
6. 原有搜索、属性标签与分类筛选、双击进入、返回选中/搜索、内部文档编辑、冲突与草稿保护、任务和全局台账同源行为保留。测试功能仍默认关闭。

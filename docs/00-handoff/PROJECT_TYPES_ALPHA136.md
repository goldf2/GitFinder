# 项目类型与目录层级 · alpha.136

## 2026-09-10 · 已确认方向与实现

- 用户要求：主区不再展示大型项目组分类；左侧单一“项目类型”入口承载分类筛选，真实父子项目按目录层级展示。
- 保留现有 `projectGroups` 数据和稳定 ID，仅调整语义及界面；类型可以交叉分类，不产生目录父子关系、不移动文件。
- 左侧项目类型默认折叠，展开后选择类型、未分类或编辑类型；创建/删除类型保留在此入口的设置中。主区只有匹配项目，不重复展示分类卡片。
- 项目目录树按最近的已项目化父目录嵌套；未项目化的中间文件夹不是项目节点；子项目的仓库不重复出现在父项目下。
- 类型筛选写入已有 contentQuery，随标签页保存/恢复；“所有项目”清除类型条件，目录浏览不继承分类筛选。
- 选择项目目录时同步右侧项目详情，使用既有详情展示，不改变文件选择或目录内容。
- 验证：39 项专项回归通过；`npm run check` 1115/1115，258 个 JavaScript 文件检查通过。实际安装交互待验证。
- 本次承接原工作区已有的项目组侧栏草稿，其他 README、项目元数据、历史交接文档等未提交修改保持原状。

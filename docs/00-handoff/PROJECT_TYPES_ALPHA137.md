# 类型列表间距与增删改入口 · alpha.137

## 2026-09-10 08:11 +0800

- 用户截图：项目类型行间距过大，类别添加、修改、删除入口不清晰。
- 根因：类型行使用没有布局规则的 `sidebar-shortcut-row`，透明编辑按钮换到下一行仍占位；沿用固定按钮的隐藏样式，编辑入口不容易发现。
- 修复：独立 `project-type-row` 两列横排，行高至少 28px、行间 2px；类别和编辑按钮同一行，“编辑”常显。新建入口及设置窗口的删除功能继续复用，不改变分类数据。
- 验证：`npm run check` 1117/1117，通过 258 个 JavaScript 语法检查。安装版间距和类别增删改待验收。
- 下一步：从提交打包，在隔离配置实测新增、重命名、删除与实际行高，再恢复用户原配置并推送。用户确认有效后归档修复报告。

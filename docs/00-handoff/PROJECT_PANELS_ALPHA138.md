# alpha.138 项目选择、卡片大小与面板收起

2026-09-10 +0800。

目标：项目卡片单击可选择并联动详情；提供可记忆的小/中/大尺寸；左右辅助区能完全收起并从顶部恢复。

根因：项目集合渲染未绑定 DirectorySelectionController；该控制器原来仅识别目录卡片，且项目集合不属于目录浏览上下文。三栏约束有最小宽度但无隐藏状态。

实现：项目卡片接入选择与多选，按钮不劫持卡片选择，双击/Enter 打开项目。项目页“卡片大小”实时调整列宽及小卡片内容密度。顶部“左侧栏/详情栏”切换整栏和拖动柄，隐藏状态独立保存，不覆盖展开宽度。

配置：projectCardSize、sidebarHidden、detailPanelHidden；无数据迁移，不更改项目清单或类型。

验证与发布：正在执行自动检查、从提交打包及安装版交互验收；尚未推送。

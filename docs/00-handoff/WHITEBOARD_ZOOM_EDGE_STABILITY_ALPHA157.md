# alpha.157 · 白板缩放连线稳定性

## 现象

白板缩放视图时，关系连线会重新选择避障路径，导致同一条连线在缩放过程中跳动或改变走向。

## 根因

关系画布的 `onMoveEnd` 在每次缩放结束后调用 `rerouteFlowConnections`。路由器会根据当前视口缩放值计算标题障碍物的世界坐标尺寸，因此缩放被错误地当成了节点几何变化。

## 修复

- 缩放结束只更新 `viewportZoom` 并通知控制器。
- 删除缩放事件中的连线路径重算。
- 连线粗细、透明度和虚线间距仍由 `RelationshipEdge` 随缩放实时调整；拖动节点、改变布局或刷新数据时仍会正常重算路径。

# alpha.152 自动排列缩短访问点连线

2026-09-12 +08:00。用户要求优化自动排列，而不是调整线宽。

- 根因：全局树布局的访问点层受大 Project 容器宽度影响；全部自动排列在已开启时实际上关闭排列，无法再次整理。
- 自动整理时将未锁定的外部访问点从全局层级列中分离，按关联部署中心寻找邻近空位。共享访问点按多个部署的平均中心放置，候选位置按总距离择优，避开容器、标题和已放置卡片。不修改成员归属、事实关系或锁定访问点。类别分列仍保持其按类型分列的明确语义。
- 重复点击全部自动排列始终重新整理；停用单组自动排列仍保留现有入口。
- npm run check：1146 项测试通过；新增独占/共享访问点、锁定位置、无重叠、归属保留和重复稳定回归。
- 当前缓存的隔离内存副本验证：84 节点，33 条 exposes 关系；平均端点距离 2490 → 547，最大 6821 → 1008，重复重排相同。未写入用户文件，数值为世界坐标欧氏距离，不是屏幕像素或曲线路径长度。
- 最终安装版可见验收见下方记录。

- a7b3cae：新增本机动态布局位置版本标记 positionVersion: 1，新保存的坐标在同步后恢复，仍由实时拓扑决定成员归属；旧的无版本坐标不改变原有兼容策略。
- 当前缓存隔离副本：重排与重新注入相同拓扑后均为平均 547、最大 1008。扩展 UI 控制器回归覆盖位置跨刷新保留；1146 测试通过，267 个 JavaScript 文件检查通过。

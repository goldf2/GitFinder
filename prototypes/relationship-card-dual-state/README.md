# 双态部署卡片原型

这是独立于正式关系白板的交互原型，用于确认卡片的简略态和详情态，不会被 Electron 打包，也不会写入 GitFinder 配置。

## 设计范围

- 简略态：资源身份、服务状态、环境、分支、提交、服务器和更新时间。
- 详情态：补充访问延迟、最近部署、最近失败、代码来源、提交说明、运行主机、访问端点、部署备注和待办摘要。
- 右上角按钮与底部按钮均可切换状态，并共享相同的 `aria-expanded` 语义。
- 卡片宽度和连接点位置固定；详情只向下展开。
- 状态选择器提供运行中、部署中、已停止、部署失败和服务故障五种视觉样例。

## 产品边界

- 卡片详情用于白板内快速判断；完整属性编辑仍由现有浮动详情窗口承担。
- 本原型没有改动 `src/renderer` 下的正式白板实现。

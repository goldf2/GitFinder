# 全览关系卡片原型

本原型验证“统一卡片视觉、保留资源语义”的关系白板方案，不修改正式 GitFinder 白板代码。

## 关键设计

- 仓库、部署、主机和访问点共用同一卡片模板，但仍保留类型标签与连线约束。
- 页面顶部并列展示运行中、已停止、故障、有待办和无待办五种简略卡片样例。
- 运行状态和人工关注状态分开表达：状态徽标位于右上，待办/提醒色条位于卡片左侧。
- 卡片主体按状态轻染底色：运行中默认淡绿、停止淡灰、故障淡红，强度可在视觉设置中调整或关闭。
- 状态颜色统一为三类：绿色表示正常（包括仓库已同步）、红色表示预警/故障、灰色表示停止/失效；仓库蓝绿色仅作为资源类型色。
- 紫色表示待办、橙色表示提醒、红色表示逾期；没有待办时简略态明确显示“无待办”。
- 示例关系覆盖一个仓库对应多个部署、一个部署连接多个主机和多个访问点。
- 每张卡片独立支持简略态与详情态，详情展开后连线锚点保持在固定位置。
- 卡片展开会推开同一泳道内后续元素，画布高度和关系线随布局变化同步更新，不使用覆盖式详情。
- 筛选支持多选：同一分组内采用“任一条件”，运行状态、关注状态和资源类型之间采用“同时满足”。
- 筛选采用三级视觉层级：命中节点高亮、一跳关系上下文默认 34% 可见、无关节点默认 7% 可见；节点仍保留在原位置。
- 未命中项可在筛选菜单中切换为“低可视”或“隐藏”；隐藏模式仅保留真正命中的节点与命中节点之间的关系线。
- 白板工具栏中的双态按钮可一键展开全部卡片详情，再次点击统一收起；单张卡片仍可独立切换。
- 有待办的卡片在简略态显示数量徽标，展开详情后显示待办/提醒/逾期条目的名称与时间；无待办卡片不显示空列表。
- “视觉设置”浮动面板提供柔和、聚焦、强对比预设，并可单独调整节点、关系线、色彩和命中外圈；调整实时预览并保存在当前浏览器本地。

## 边界

- 原型只使用静态示例数据，不连接 Coolify；视觉偏好仅保存在当前浏览器本地，不写入正式 GitFinder 配置。
- 正式白板是否替换，等待用户批准后再执行。
